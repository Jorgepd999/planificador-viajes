# Comparativa con Aplicaciones Existentes

## Aplicaciones actuales en el mercado

### TripAdvisor
Plataforma global con millones de reseñas de hoteles, restaurantes y atracciones. Permite crear listas de sitios a visitar, pero no genera itinerarios automáticos ni gestiona presupuestos de forma integrada.

### Google Travel
Herramienta de Google que agrega vuelos, hoteles y lugares de interés. Ofrece sugerencias de actividades, pero los itinerarios son manuales y dependen de la búsqueda activa del usuario.

### Roadtrippers
Orientado a rutas por carretera. Permite planificar paradas pero no distribuye el tiempo ni el presupuesto de forma automática entre actividades.

### Sygic Travel
Aplicación móvil que permite crear itinerarios día a día de forma manual, con acceso a una base de datos de puntos de interés. Requiere configuración manual de cada día.

---

## Comparativa y diferenciación

### Generación automática frente a planificación manual
- Las aplicaciones existentes requieren que el usuario construya el itinerario seleccionando cada actividad de forma individual.
- El Planificador de Viajes genera el itinerario completo de forma automática, distribuyendo los lugares por días según las preferencias, las horas disponibles (8 h/día) y el presupuesto indicado.

### Control del presupuesto
- Ninguna de las herramientas analizadas integra de forma nativa el control del gasto por día dentro del propio itinerario.
- Esta aplicación distribuye el presupuesto total entre los días del viaje y solo incluye actividades que lo respeten.

### Personalización por preferencias
- Las grandes plataformas ofrecen recomendaciones basadas en popularidad o valoraciones globales.
- Este sistema filtra los lugares según el tipo de actividad preferida por el usuario: cultura, naturaleza, gastronomía u ocio.

### Exportación a PDF
- La aplicación permite descargar el itinerario completo en PDF para su uso sin conexión, algo que muchas herramientas gratuitas no ofrecen.

### Orientación técnica
- Esta solución está desarrollada como proyecto propio, sin dependencia de servicios externos de pago.
- Al ser código abierto y propio, puede ampliarse y adaptarse sin restricciones de licencia.

## Ventajas de esta aplicación

- Generación automática e inteligente de itinerarios.
- Control integrado del presupuesto diario.
- Filtrado por preferencias de actividad.
- Exportación a PDF sin coste adicional.
- Interfaz web y API REST en un mismo proyecto.
- Base de datos propia, sin dependencia de APIs externas de pago.
- Arquitectura ampliable (nuevos destinos, tipos de actividad, integraciones).
