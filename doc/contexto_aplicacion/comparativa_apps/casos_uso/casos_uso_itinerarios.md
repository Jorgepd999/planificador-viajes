# Casos de Uso — Itinerarios

| **Caso de Uso** | **Actor** | **Descripción** |
|---|---|---|
| Generar itinerario | Usuario | Crear un itinerario automático indicando nombre, destino, duración, presupuesto y preferencias. El sistema distribuye los lugares disponibles por días respetando el presupuesto. |
| Listar itinerarios | Usuario | Ver todos los itinerarios creados. |
| Ver detalle de itinerario | Usuario | Consultar el itinerario completo día a día con los lugares asignados, sus tipos, precios y duración. |
| Marcar como favorito | Usuario | Añadir o quitar un itinerario de la lista de favoritos. |
| Ver itinerarios favoritos | Usuario | Filtrar la lista para ver solo los itinerarios marcados como favoritos (vía API REST). |
| Eliminar itinerario | Usuario | Borrar un itinerario del sistema. |
| Exportar a PDF | Usuario | Descargar el itinerario completo en formato PDF para su uso sin conexión. |
| Buscar itinerario | Usuario | Filtrar la lista por nombre o destino mediante el buscador. |
