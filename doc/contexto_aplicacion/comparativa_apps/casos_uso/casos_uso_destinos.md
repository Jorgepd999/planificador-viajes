# Casos de Uso — Destinos

| **Caso de Uso** | **Actor** | **Descripción** |
|---|---|---|
| Listar destinos | Usuario | Ver la lista completa de destinos turísticos disponibles. |
| Consultar destino por ID | Usuario | Ver los detalles de un destino concreto. |
| Crear destino | Administrador | Registrar un nuevo destino con nombre, país y descripción. |
| Editar destino | Administrador | Modificar los datos de un destino existente. |
| Eliminar destino | Administrador | Borrar un destino del sistema. |
| Buscar destino | Usuario | Filtrar la lista de destinos por nombre o país mediante el buscador. |
