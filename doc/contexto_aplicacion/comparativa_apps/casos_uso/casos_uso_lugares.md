# Casos de Uso — Lugares Turísticos

| **Caso de Uso** | **Actor** | **Descripción** |
|---|---|---|
| Listar lugares | Usuario | Ver todos los lugares de interés registrados en el sistema. |
| Consultar lugar por ID | Usuario | Ver los detalles de un lugar concreto. |
| Crear lugar | Administrador | Registrar un nuevo lugar con nombre, tipo, precio, duración de visita y destino asociado. |
| Editar lugar | Administrador | Modificar los datos de un lugar existente. |
| Eliminar lugar | Administrador | Borrar un lugar del sistema. |
| Filtrar por tipo | Usuario | Filtrar la lista de lugares por tipo de actividad (cultura, naturaleza, gastronomía, ocio). |
| Buscar lugar | Usuario | Filtrar la lista por nombre, tipo o destino mediante el buscador. |
